3.2 การเลือกส่วนประกอบ
ไมโครคอนโทรลเลอร์  ESP32 CAM ทำหน้าที่ส่งข้อมูลภาพผ่าน Wi-Fi ไปยังอุปกรณ์อื่นได้ เช่น คอมพิวเตอร์, สมาร์ทโฟน หรือเซิร์ฟเวอร์คลาวด์ เพื่อแสดงผลแบบเรียลไทม์ (Video Stream) และโต้ตอบกับอุปกรณ์ภายนอก: ESP32 สามารถควบคุมอุปกรณ์ภายนอกที่เชื่อมต่อกับขา GPIOs ได้ เช่น เซ็นเซอร์ตรวจจับ, หรือไฟ LED อื่นๆ
ตัวขับมอเตอร์ L298N เป็น DC Motor ใช่ในการเปลี่ยนทิศทางกระแสไฟฟ้าและจะหมุนกลับทิศเมื่อกระแสไหลผ่านขดลวดในทิศทางตรงกันข้าม H-Bridge มีสวิตช์ 4 ตัวที่จัดเรียงกันเป็นรูปตัว 'H' ทำให้สามารถสลับทิศทางการไหลของกระแสผ่านมอเตอร์ได้ตามต้องการ H-Bridge (เอช-บริดจ์) คือวงจรอิเล็กทรอนิกส์ประเภทหนึ่งที่ถูกออกแบบมาเพื่อควบคุมทิศทางการไหลของกระแสไฟฟ้าผ่านโหลด โดยเฉพาะอย่างยิ่งใช้ในการ ควบคุมทิศทางการหมุนของมอเตอร์กระแสตรง (DC Motor)
ตัวปรับแรงดัน Voltage Regulator 7805(TO-220) ทำงานโดยหลักการ "ควบคุมแรงดัน" (Shunt Regulation หรือ Series Regulation) ในกรณีของ 7805 เป็นแบบ Series Regulator คือมีการควบคุมกระแสที่ไหลผ่านตัวมันเองเพื่อรักษาแรงดันขาออกให้คงที่
คอนเนคเตอร์เซ็นเซอร์ SN-IRLINE-MOD หรือ IR Line Tracking Module เป็นโมดูลเซ็นเซอร์ที่ใช้สำหรับ ตรวจจับเส้น โดยเฉพาะอย่างยิ่งเส้นสีดำบนพื้นผิวสีขาว (หรือเส้นขาวบนพื้นดำ) การทำงานของมันอาศัยหลักการสะท้อนของแสงอินฟราเรด
แหล่งจ่ายไฟ แบตเตอรี่ Li-Po (Lithium Polymer) เป็นแบตเตอรี่แบบชาร์จซ้ำได้ (Rechargeable Battery) ที่ได้รับความนิยมอย่างมากในปัจจุบัน โดยเฉพาะในอุปกรณ์อิเล็กทรอนิกส์แบบพกพา

3.3.3 อธิบายการทำงานของ L298N

 ![image](https://github.com/user-attachments/assets/1216d49c-6c26-441f-b898-7904e3e50c90)
 
รูปที่ 3.4 การทำงานภายใน L298
ควบคุมด้วยสัญญาณจากขา C (10) และ D (12):
กรณีที่ 1: หมุนไปในทิศทางหนึ่งในกรณีนี้ สัญญาณที่ขา C (10) เป็น Logic '1' (High) และขา D (12) เป็น Logic '0' (Low) เปรียบเสมือนการเปิด-ปิดสวิตช์ในวงจร H-Bridge โดย Driver 3 จะทำงานและเชื่อมต่อขา 13 ของมอเตอร์เข้ากับแหล่งจ่ายไฟบวก (+Vs) ในขณะที่ Driver 4 จะไม่ทำงานและเชื่อมต่อขา 14 ของมอเตอร์เข้ากับกราวด์ (GND)
ผลที่ได้คือ กระแสไฟฟ้าจะไหลจาก +Vs ผ่าน Driver 3 ไปยังขา 13 ของมอเตอร์ จากนั้นไหลผ่านตัวมอเตอร์ (M) ไปยังขา 14 และไหลผ่าน Driver 4 ลงสู่กราวด์ (GND) โดยมี Sense Resistor RS ทำหน้าที่วัดกระแส การไหลของกระแสในทิศทางนี้จะทำให้มอเตอร์เริ่มหมุนไปในทิศทางแรกที่กำหนดไว้
กรณีที่ 2: หมุนไปในทิศทางตรงกันข้ามเพื่อเปลี่ยนทิศทางการหมุนของมอเตอร์ เราจะกลับสัญญาณควบคุม กล่าวคือ สัญญาณที่ขา C (10) จะเป็น Logic '0' (Low) และขา D (12) จะเป็น Logic '1' (High) ในสถานะนี้ Driver 3 จะไม่ทำงานและเชื่อมต่อขา 13 ของมอเตอร์เข้ากับกราวด์ (GND) ส่วน Driver 4 จะทำงานและเชื่อมต่อขา 14 ของมอเตอร์เข้ากับแหล่งจ่ายไฟบวก (+Vs)
กระแสไฟฟ้าจะไหลในทิศทางตรงกันข้ามกับกรณีแรก นั่นคือไหลจาก +Vs ผ่าน Driver 4 ไปยังขา 14 ของมอเตอร์ จากนั้นไหลผ่านตัวมอเตอร์ (M) ไปยังขา 13 และไหลผ่าน Driver 3 ลงสู่กราวด์ (GND) การไหลของกระแสที่ย้อนกลับทิศทางนี้จะส่งผลให้มอเตอร์หมุนไปในทิศทางตรงกันข้าม
กรณีที่ 3: หยุดมอเตอร์แบบเบรก (Brake/Short Brake)การหยุดมอเตอร์ด้วยวิธีนี้จะทำให้มอเตอร์หยุดหมุนอย่างรวดเร็ว โดยการตั้งค่าสัญญาณที่ขา C (10) และ D (12) ให้เป็น Logic '1' (High) พร้อมกัน (หรืออาจใช้ Logic '0' (Low) พร้อมกันก็ได้ ขึ้นอยู่กับการออกแบบวงจร แต่ใน L298N มักใช้ High-High)เมื่อสัญญาณทั้งสองขาเป็น High พร้อมกัน ขา 13 และ 14 ของมอเตอร์จะถูกเชื่อมต่อเข้ากับแหล่งจ่ายไฟเดียวกัน ซึ่งทำให้ปลายทั้งสองด้านของมอเตอร์เกิดการลัดวงจรภายในตัววงจร H-Bridge กระแสไฟฟ้าที่เกิดจาก Back EMF (แรงเคลื่อนไฟฟ้าต้านกลับ) ของมอเตอร์จะไหลย้อนกลับผ่านตัวมอเตอร์เองและวงจร H-Bridge การไหลย้อนกลับของกระแสนี้จะสร้างแรงต้านทานการหมุน (Dynamic Braking) ขึ้นมาอย่างรวดเร็ว ทำให้มอเตอร์หยุดหมุนในทันทีหรือเกือบจะทันที
กรณีที่ 4: หยุดมอเตอร์แบบฟรีรัน (Coast/Free Run)วิธีนี้เป็นการหยุดมอเตอร์แบบค่อยเป็นค่อยไป โดยการตั้งค่าสัญญาณที่ขา C (10) และ D (12) ให้เป็น Logic '0' (Low) พร้อมกัน หรือการปิดใช้งานขา Enable (OV_en) โดยตั้งค่าเป็น Logic '0'
เมื่อเกิดกรณีนี้ เอาต์พุตที่ขา 13 และ 14 ของมอเตอร์จะเข้าสู่สถานะ High-Z (High Impedance) ซึ่งหมายถึงวงจรเปิด (Open Circuit) ไม่มีกระแสไฟฟ้าไหลผ่านมอเตอร์ มอเตอร์จะค่อยๆ ชะลอการหมุนและหยุดลงเองตามธรรมชาติ เนื่องจากแรงเสียดทานภายในตัวมอเตอร์และแรงต้านทานจากภายนอก เป็นการหยุดแบบที่ไม่มีการใช้เบรกไฟฟ้าเข้ามาช่วย ทำให้มอเตอร์หมุนค้างต่อไปได้ระยะหนึ่งก่อนจะหยุดสนิท
